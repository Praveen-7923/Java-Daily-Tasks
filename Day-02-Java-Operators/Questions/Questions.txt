JAVA DAILY TASKS
DAY 02 - JAVA OPERATORS

Task 01:
Write a Java program to accept two numbers from the user
and perform Addition, Subtraction, Multiplication, Division,
and Remainder operations.

Task 02:
Write a Java program to calculate the total shopping bill.
Accept the price and quantity of three different products
and calculate the total amount.

Task 03:
Write a Java program to accept a number of seconds from the user
and convert it into Hours, Minutes, and Seconds.

Task 04:
Write a Java program to calculate an employee's net salary.
Accept Basic Salary, HRA percentage, and DA percentage.
Calculate HRA, DA, and Net Salary.

Formula:
HRA = Basic Salary × HRA Percentage / 100
DA = Basic Salary × DA Percentage / 100
Net Salary = Basic Salary + HRA + DA

Task 05:
Write a Java program to swap two numbers without using
a third variable.
