JAVA DAILY TASKS
DAY 03 - JAVA IF / ELSE CONDITIONS

Task 01:
Write a Java program to accept a number and check whether
the number is positive, negative, or zero.

Task 02:
Write a Java program to accept a number and check whether
the number is even or odd.

Task 03:
Write a Java program to accept a person's age and check
whether the person is eligible to vote.
Age 18 or above is eligible.

Task 04:
Write a Java program to accept marks and display the grade.

90 - 100  : A
80 - 89   : B
70 - 79   : C
60 - 69   : D
Below 60  : F

Task 05:
Write a Java program to accept two numbers and find the
larger number. If both numbers are equal, display
"Both numbers are equal".
