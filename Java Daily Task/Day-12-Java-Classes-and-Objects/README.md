# Day 12 – Java Classes and Objects

This folder contains five Java practice programs focused on classes, objects, fields, and methods.

## Topics Covered

- Class declaration
- Object creation using the `new` keyword
- Instance variables and fields
- Calling methods using the dot operator
- Methods with parameters and return values
- Creating multiple objects from one class

## Tasks

| Task | Description |
|---|---|
| Task 01 | Create and display a Student object |
| Task 02 | Create and display an Employee object |
| Task 03 | Add two numbers using a class method |
| Task 04 | Calculate the area of a rectangle |
| Task 05 | Create and display two Student objects |

## How to Run

Open a terminal in the `Solutions` folder.

Compile all five programs:

```bash
javac *.java
```

Run each program:

```bash
java Task01
java Task02
java Task03
java Task04
java Task05
```

## Learning Goal

Understand how classes define the structure of objects, how objects store individual data, and how methods implement behavior in Java.
