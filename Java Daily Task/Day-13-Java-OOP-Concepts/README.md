# Day 13 – Java OOP Concepts

This folder contains five Java programs demonstrating the fundamental concepts of Object-Oriented Programming.

## Topics Covered

- Encapsulation
- Inheritance
- Compile-time Polymorphism
- Runtime Polymorphism
- Abstraction
- Method Overloading
- Method Overriding
- Abstract Classes and Methods

## Tasks

| Task | Description | Concept |
|---|---|---|
| Task 01 | Bank Account | Encapsulation |
| Task 02 | Animal and Dog | Inheritance |
| Task 03 | Method Overloading | Compile-time Polymorphism |
| Task 04 | Method Overriding | Runtime Polymorphism |
| Task 05 | Abstract Shape Class | Abstraction |

## How to Run

Open the terminal inside the Solutions folder.

Compile all programs:

```bash
javac *.java
```

Run each program:

```bash
java Task01
java Task02
java Task03
java Task04
java Task05
```

## Learning Goal

Understand the four major OOP principles and learn how Java uses classes, inheritance, method overloading, method overriding, and abstraction to build reusable and maintainable applications.
