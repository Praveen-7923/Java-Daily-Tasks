# Day 11 – Java 2D Arrays

This folder contains five Java practice programs focused on two-dimensional arrays and matrix operations.

## Topics Covered

* Declaring and initializing 2D arrays
* Accessing elements using row and column indexes
* Using nested loops
* Reading and displaying matrix values
* Calculating the sum of matrix elements
* Matrix addition
* Finding the largest element

## Tasks

| Task    | Description                              |
| ------- | ---------------------------------------- |
| Task 01 | Print a 3×3 matrix                       |
| Task 02 | Read and display a 2×3 matrix            |
| Task 03 | Find the sum of matrix elements          |
| Task 04 | Add two 2×2 matrices                     |
| Task 05 | Find the largest element in a 3×3 matrix |

## How to Run

Open a terminal in the `Solutions` folder.

Compile all programs:

```bash
javac *.java
```

Run an individual program:

```bash
java Task01
java Task02
java Task03
java Task04
java Task05
```

## Learning Goal

Improve Java programming fundamentals, nested-loop logic, matrix manipulation, and problem-solving skills through daily practice.
