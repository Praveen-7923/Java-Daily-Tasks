# ▶️ How to Run the Programs

Navigate to the required `Solutions` folder.

### Step 1: Open Terminal

Open Command Prompt or PowerShell inside the `Solutions` folder.

### Step 2: Compile the Java Program

```bash
javac Q01_ProgramName.java
```

### Step 3: Run the Program

```bash
java Q01_ProgramName
```

### Example

```bash
javac Q01_StudentDetails.java
java Q01_StudentDetails
```

The same process can be followed for the remaining Java programs.
